{# Formatage des valeurs potentiellement inconnues, et marques de données. Un seul endroit à corriger si la convention évolue. Rappel du piège (AGENTS.md 9) : dans Tera, null ET 0 sont falsy, donc {% if valeur %} afficherait un tiret sur un zéro pourtant constaté. Le filtre `default` est le seul moyen correct de les distinguer, et c'est sur son résultat qu'on décide aussi de la classe CSS. Même piège sur les paliers de la matrice : le palier 0 est valide, donc on passe par une sentinelle -1 plutôt que par un test de vérité. #} {% macro num(v) %} {%- set text = v | default(value="—") -%} {{ text }} {%- endmacro num %} {% macro cell(v) %} {%- set text = v | default(value="—") -%} {{ text }} {%- endmacro cell %} {# Cellule de matrice : teintée selon son palier de magnitude.
